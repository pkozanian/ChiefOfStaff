# Chief of Staff

A private, memory-backed **chief of staff** that runs in the Claude or ChatGPT desktop app on your own
computer. This is the repo that builds it.

Want to know what it actually does with your information before you install it?
**[How it works](https://chiefofstaff.team/brain/)** explains every behavior in plain language, and
renders the complete rulebook it runs on. Nothing is hidden.

## ⚡ Quick Install

Chief of Staff **prompt-boots**: paste one sentence and it fetches itself.

**Step 1 -- Make an empty folder** 
```
name it `ChiefOfStaff`, anywhere you keep files. Leave it empty.
```
>
**Step 2 -- Open that folder in your app**

| | |
|---|---|
| **[Claude&nbsp;desktop](https://claude.com/download)** | Code tab → Local → Select folder → your empty `ChiefOfStaff` folder |
| **[ChatGPT&nbsp;desktop](https://chatgpt.com/download/)** | New chat → Choose Project → Add folders ChatGPT can read → your empty `ChiefOfStaff` folder → Create Project |

```
Claude's tab is called "Code," but you won't write any. It's just how Claude opens a folder on
your computer, and it needs a paid Claude plan.
ChatGPT is included with free plans.
```
**Step 3 -- Paste this, and you're done**

```
Install https://chiefofstaff.team
```

That's a prompt boot: it fetches itself, unpacks into your folder, and starts setting up.

> [!TIP]
> **You'll know it worked** when it introduces itself as your chief of staff and asks whether this is
> for your work or your personal life. That's the start of a guided setup: six short steps, about 10
> to 15 minutes, nothing to prepare, and you can stop any time and pick up where you left off.

<details>
<summary>Prefer to do it by hand, or can't find the folder picker?</summary>

<br>

Download [`cos.zip`](https://cos.team/dist/cos.zip), unzip it into that folder yourself, then say
"onboard me".

If there's no way to pick a folder, check you're in the **desktop app** on your Mac or Windows
computer and signed in, not Claude or ChatGPT in a web browser.

</details>
